# 1. Architecture de l’AMM

Curve Crypto organise des pools pour actifs volatils autour d’un invariant spécialisé. Les contrats séparent le pool, le token LP et les paramètres de frais.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
